Код, сайты, дизайн, фото, видео и прототипы приложений. Файлы обрабатываются локально в браузере.

Личное и общее хранилище синхронизируется только между вкладками этого браузера. Для удалённой команды нужен сервер.

HTML, JavaScript и Python. Python запускается через Pyodide и требует подключения к интернету при первом запуске.
